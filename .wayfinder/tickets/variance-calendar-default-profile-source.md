# Source of the common default profile

Type: Grilling (HITL)

## Question
Should callers be required to provide a common default intraday decay profile, or should the calendar provide an implicit all-one profile when no profile is supplied?

## Resolution
Use an implicit all-one decay profile if no common or weekday-specific profile is supplied.
