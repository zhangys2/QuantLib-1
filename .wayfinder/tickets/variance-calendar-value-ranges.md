# Weight and multiplier value ranges

Type: Grilling (HITL)

## Question
What values should be accepted for day-category weights and decay multipliers: nonnegative values (including zero), strictly positive values, or another range?

## Resolution
Both day-category weights and decay multipliers must be finite and nonnegative; zero is allowed.
